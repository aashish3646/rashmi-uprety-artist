# rashmi-uprety-artist

Official digital portfolio website for Rashmi Uprety — Actress & Theatre Artist.

## Tech Stack

- **Framework:** React 19
- **Build Tool:** Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Routing:** React Router v7
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Local Development

To start the local development server:

```bash
npm run dev
```

## Production Build

To compile and build the production bundle:

```bash
npm run build
```

To preview the built application locally:

```bash
npm run preview
```
